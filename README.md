# AI Crypto Market Analyzer – Web version

Folder contents
- AI_Crypto_Analyzer_OpenRouter_Free_Fallback_FIXED__2_.py  <- your ORIGINAL program (unchanged)
- app.py            <- web GUI that runs your original program
- requirements.txt  <- libraries
- .python-version   <- Python 3.12 (the original needs 3.10+)

Run on your own PC
    pip install -r requirements.txt
    streamlit run app.py

Put it online (free, shareable link) - Streamlit Community Cloud
1. Create a GitHub repository and upload ALL files in this folder.
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Click "Create app" -> choose your repo -> Main file path: app.py -> Deploy.
4. Share the link you get (https://yourname-yourapp.streamlit.app).

Each visitor types their OWN OpenRouter key in the page. Nothing is stored.
Do NOT put your own key in the code or GitHub.
